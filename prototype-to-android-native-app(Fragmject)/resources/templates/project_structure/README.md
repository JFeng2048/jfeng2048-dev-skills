# Deprecated single-module template

This directory is retained only as a historical reference. Its source files and dependency catalog use an obsolete single-module baseline; do not copy it, treat its versions as current, or use it for new projects. The active renderer does not read this directory.

The active template is `resources/templates/modular_project_structure/`. It generates the app shell, core modules, feature `api` / `impl` pairs, and `build-logic`. Resolve current stable compatible versions at generation time and pass them through `proto_context.json`.
